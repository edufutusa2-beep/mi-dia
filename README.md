# Mi Día y Finanzas

Micro app personal: agenda con avisos y finanzas (ingresos, gastos, balance y margen).

Ábrela en Safari en el iPhone y pulsa **Compartir → Añadir a pantalla de inicio** para usarla como app a pantalla completa. Los datos se guardan en el propio dispositivo; usa *Finanzas → Copia de seguridad* para copiarlos o restaurarlos.
